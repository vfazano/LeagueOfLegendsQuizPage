# 🎮 League of Legends Quiz

> Um quiz interativo inspirado no universo de **League of Legends**, desenvolvido para testar os conhecimentos dos jogadores sobre campeões, habilidades e elementos do jogo.

O projeto foi criado com foco em **desenvolvimento Front-end**, utilizando React e TypeScript para construir uma experiência interativa, dinâmica e responsiva.

## 🎯 Sobre o projeto

O **League of Legends Quiz** apresenta uma sequência de perguntas relacionadas ao universo de League of Legends.

O usuário responde às perguntas e recebe feedback sobre seu desempenho durante a experiência.

O projeto foi desenvolvido como uma forma de praticar conceitos modernos de desenvolvimento web, principalmente **React.js, TypeScript, componentes, estados e renderização dinâmica**.

## ⚙️ Como executar

### Pré-requisitos

Antes de iniciar, tenha instalado:

* [Node.js](https://nodejs.org/)
* npm ou pnpm
* Git

### 1. Clone o repositório

```bash
git clone https://github.com/vfazano/LeagueOfLegendsQuizPage.git
```

### 2. Entre na pasta

```bash
cd LeagueOfLegendsQuizPage
```

### 3. Instale as dependências

Com npm:

```bash
npm install
```

Ou com pnpm:

```bash
pnpm install
```

### 4. Inicie o projeto

```bash
npm run dev
```

Ou:

```bash
pnpm dev
```

### 5. Abra no navegador

O Vite normalmente disponibiliza o projeto em:

```text
http://localhost:5173
```

## 🎮 Como jogar

1. Inicie o projeto.
2. Leia a pergunta apresentada.
3. Escolha uma das alternativas.
4. O sistema informa o resultado da resposta.
5. Continue até finalizar o quiz.
6. Confira sua pontuação final.
7. Reinicie e tente melhorar seu resultado.
